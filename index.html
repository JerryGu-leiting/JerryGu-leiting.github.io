Course portfolio

Robot software, built from the transport up

Projects from ROB 511. Each one is a ROS-style runtime written in C++17 that speaks a rosbridge TCP/JSON protocol on 127.0.0.1:9095. Every project reuses the publish/subscribe middleware from the one before it.

  • P3

    Forward kinematics from real URDF

    Parses a robot description, builds its kinematic tree, and publishes every link's pose in the world frame. Includes a three.js viewer and a choreographed dance.

    URDF · unit quaternions · /tf · /xform_world · finite state machine
  • P2

    Pendularm: arm dynamics and control

    Lagrangian dynamics for a 2- and 3-link planar arm, four numerical integrators, per-joint PID control, and closed-form inverse kinematics.

    dynamics · RK4 · PID · IK
  • P1

    Publish/subscribe middleware and A* planning

    A message hub and rosbridge gateway written from scratch, with a grid path planner served over it.

    pub/sub · TCP gateway · A* · binary heap
