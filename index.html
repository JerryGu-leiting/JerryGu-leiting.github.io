ROB 511 projects

ROS-style robot runtimes in C++17. Each one serves a rosbridge TCP/JSON protocol on 127.0.0.1:9095 and is graded black-box over that interface.

  • P3

    Forward kinematics from real URDF

    URDF in, world pose of every link out. Quaternion-based FK, a joint servo, an FSM choreography, and a three.js viewer.

    URDF · unit quaternions · /tf · /xform_world · finite state machine
  • P2

    Pendularm: arm dynamics and control

    Lagrangian dynamics for a 2/3-link planar arm, four integrators, per-joint PID, closed-form IK.

    dynamics · RK4 · PID · IK
  • P1

    Publish/subscribe middleware and A* planning

    Pub/sub hub and rosbridge gateway from scratch, with an A* grid planner served over it.

    pub/sub · TCP gateway · A* · binary heap
